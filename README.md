# 🍬 Nassau Candy Distributor – Product Line Profitability & Margin Performance Analysis
### Personal Project ( For Internship)

## 📌 Project Overview

This project focuses on analyzing sales, costs, gross profit, product profitability, and profit margins for **Nassau Candy Distributor**.

The objective is to transform raw sales data into meaningful business insights using an end-to-end data analytics workflow involving **Excel, SQL, and Power BI**.

The analysis identifies high-performing products, evaluates profitability across divisions and regions, and provides an interactive Power BI dashboard for business decision-making.

---

## 🎯 Business Objective

The main objective of this project is to understand:

- Overall sales and profitability performance
- Product-level sales and profit contribution
- Profit margin across products
- Gross profit performance by division
- Gross profit performance by region
- Top-performing products by gross profit
- Relationship between sales performance and profitability
- Areas where business performance can be improved
